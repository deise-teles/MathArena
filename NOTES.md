# MathArena — Notas do Projeto

## Sobre o projeto

MathArena é um jogo matemático desenvolvido com HTML, CSS e JavaScript puro, criado com o objetivo de praticar lógica de programação, manipulação de DOM, persistência de dados e conceitos fundamentais do desenvolvimento front-end.

O projeto simula uma experiência de jogo arcade/cyberpunk, onde o jogador responde operações matemáticas para acumular pontos, aumentar combos e subir de nível.

---

# Objetivos do projeto

- Praticar JavaScript na construção de aplicações interativas
- Melhorar conhecimentos em lógica de programação
- Trabalhar manipulação dinâmica de elementos HTML
- Utilizar armazenamento local com localStorage
- Criar uma interface moderna e responsiva
- Simular uma aplicação real para portfólio

---

# Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- Git
- GitHub

# Funcionalidades implementadas

## Sistema de jogo
- Perguntas matemáticas aleatórias
- Operações de soma, subtração, multiplicação e divisão
- Sistema de dificuldade
- Timer de partida
- Sistema de score
- Sistema de combo/streak
- Sistema de níveis

---

## Interface
- Tema dark/cyberpunk
- Efeitos neon
- Animações de acerto e erro
- Hover effects
- Layout centralizado com Flexbox e Grid

---

## Persistência de dados
- Ranking salvo no navegador utilizando localStorage
- Exibição de leaderboard
- Salvamento dos melhores jogadores

---

## Recursos multimídia
- Sons de acerto
- Sons de erro
- Som de game over
